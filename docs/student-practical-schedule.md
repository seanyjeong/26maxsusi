# 학생별 실기 날짜·시간

지점현황과 최종 수합의 학생별 `실기일정`에서 날짜와 시간을 입력한다.
시간은 선택 사항이며 분 단위로 설정한다. 각 화면의 대학 저장 버튼으로 반영한다.
시간만 입력한 경우 날짜를 선택하도록 안내하며 저장하지 않는다.

- 날짜만 확정: `2026-10-10`
- 날짜와 시간 확정: `2026-10-10 09:30`
- 시간 삭제: 날짜만 유지
- 날짜와 시간 모두 삭제: `null`

기존 `확정대학정보.실기일정` 문자열 열과 `_final_save` 요청 필드를 사용한다.
스키마 변경은 없다. UTC 변환 없이 입력한 시험 날짜와 시간을 보존한다.
지점현황과 최종 수합을 오가거나 새로고침해도 시간을 다시 표시한다.
대시보드는 브라우저에서 날짜·시간순으로 정렬하며, 시간이 없는 일정은 먼저 표시한다.
같은 대학·학과라도 시간이 다르면 별도 일정으로 묶는다.

검증은 테스트용 저장소와 차단된 브라우저 요청으로 수행한다. 운영 학생 데이터는 수정하지 않는다.

```sh
node --test tests/student-practical-schedule.test.js
python3 -m pytest -q tests/test_student_practical_schedule_playwright.py
```
